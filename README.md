# Dream-home
The Dream Home Layout is a modern and responsive webpage designed with HTML and styled using Tailwind CSS. It showcases a luxurious yet cozy home environment, structured in clearly defined sections for smooth navigation and visual appeal.

🔹 Layout Structure:

Header

Contains the site logo and a navigation menu (Home, Gallery, Floor Plan, Features, Contact).

Styled with a light background, shadow, and sticky positioning.

Responsive navigation bar with a mobile hamburger menu.

Hero Section

A full-screen background image of the dream home with overlay text.

Large, bold heading (e.g., "Welcome to Your Dream Home").

A short tagline and a call-to-action button (e.g., "Explore More").

Contact Section

Contact form with name, email, message fields.

Google Maps embed showing location.

Tailwind form styling with focus, rounded, and ring classes.
